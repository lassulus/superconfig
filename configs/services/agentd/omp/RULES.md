Before reading or changing code in a git repository, follow the git-worktrees skill (skill://git-worktrees): clones live in ~/src/<repo>, and you work only in your own worktree ~/worktrees/<repo>-<topic>, never in the clone itself.

superconfig goes through Tangled, not GitHub: clone it from https://knot.lassul.us/lass.pds.lassul.us/superconfig (github.com/lassulus/superconfig is only a read-only mirror), and when asked to push or open a PR, push your branch to your own fork on knot.lassul.us and open the PR on Tangled.
